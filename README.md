# EDUPULSE

A simple web development practice project for students learning HTML, CSS, and JavaScript.

## How to run
Open `edupluse.html` in any browser.

## Project purpose
This project is designed for beginners who want to practice:
- Basic frontend development
- HTML structure
- CSS styling
- JavaScript functions and DOM handling
- Making meaningful pull requests on GitHub

## How to contribute
1. Fork the repository
2. Clone your fork
3. Create a new branch
4. Make your changes
5. Commit and push the branch
6. Open a pull request

## Contact
If you want to discuss issues or ideas, create an Issue on GitHub.
